## Description (for LinkedIn credential section)

8-week intensive course covering the full LLM engineering stack — from API fundamentals to autonomous multi-agent systems deployed in production.

**Core areas covered:**

- Frontier LLM APIs (OpenAI, Anthropic, Google, Groq, Grok, DeepSeek) and prompt engineering
- Gradio application development and multi-model pipelines
- Open source models via HuggingFace: image generation (SDXL, FLUX), tokenizers, 4-bit quantization (QLoRA/NF4), Whisper ASR
- RAG (Retrieval-Augmented Generation): LangChain, ChromaDB, semantic chunking, reranking, query rewriting, LLM-judge evaluation
- Code generation: Python to C++ and Rust using frontier models, compilation benchmarking
- Large-scale data engineering: 820,000-item Amazon product dataset, Groq Batch API, classical ML (XGBoost, Random Forest)
- Fine-tuning: OpenAI fine-tuning API (GPT-4.1-nano) and QLoRA fine-tuning of Llama 3.2-3B (3B parameters) on 400k examples — achieving 39.85 RMSE vs GPT-5.1 at 44.74
- Agentic AI systems: Modal.com cloud deployment, multi-agent orchestration (ScannerAgent, FrontierAgent, SpecialistAgent, EnsembleAgent, AutonomousPlanningAgent), Pushover push notifications, W&B experiment tracking

**Key result:** Fine-tuned a 3-billion-parameter open source model that outperformed GPT-5.1 on domain-specific price prediction — the practical proof that targeted fine-tuning beats raw model scale.
